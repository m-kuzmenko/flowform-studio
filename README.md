# Flowform Studio landing

Статический продуктовый лендинг Flowform Studio. Он также подготовлен к подключению аналитики для лабораторных работ по веб-аналитике.

## Локальный просмотр

Из этой директории:

```bash
python3 -m http.server 4173
```

Затем открыть `http://localhost:4173`.

## Публикация

1. Создать отдельный репозиторий GitHub.
2. Загрузить содержимое этой папки в корень репозитория.
3. В настройках GitHub включить Pages из ветки `main`, каталог `/ (root)`.
4. После появления публичного адреса зарегистрировать именно его в сервисах статистики.

## Аналитика

Все места для кодов счётчиков и событий вынесены в `assets/js/analytics.js`. Перед публикацией лабораторных работ нужно добавить реальные коды LiveInternet, Rambler/Top-100 и Рейтинга Mail.ru на каждую HTML-страницу.
